# NewWorld — Projecte Intermodular SMX

Els aficionats a l'anime i al manga necessiten consultar informació sobre sèries, personatges i mangas en diferents pàgines web. NewWorld vol resoldre aquest problema amb un programa que permeta cercar, classificar i organitzar tota aquesta informació en un mateix lloc, així com guardar una llista de preferits.

## Autor
- ianherrero (@ianhervan)

## Rols simulats
- **Rol A** — Organització de les dades d'animes, mangas i personatges.
- **Rol B** — Programació de les cerques, els filtres per gènere i la gestió de preferits.
- **Rol C** — Proves del programa, documentació i gestió del repositori a GitHub.

## Contingut del repositori
- `documents/` — Document de Repte (Annex A).
- `documents/fitxes/` — Fitxes d'activitat (Annex B).
- `configuracio/` — Configuracions tècniques del projecte quan s'execute.
